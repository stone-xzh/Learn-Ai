# 写作与发布

[返回仓库首页](../README.md) · [打开博客](https://stone-xzh.github.io/Learn-Ai/)

日常写作只需要用到 `posts/` 目录。Markdown 是带有简单排版标记的纯文本，不需要写网页代码。

## 发布一篇新文章

1. 打开 [文章模板](../templates/post.md)，复制它的全部内容。
2. 进入 [posts 文章目录](../posts)，点击 **Add file → Create new file**。
3. 文件名采用 `YYYY-MM-DD-英文名称.md`，例如 `2026-10-22-my-first-note.md`。已经在 `posts/` 目录时，不要再输入一次 `posts/`。
4. 粘贴模板，修改开头的文章信息，再写正文。
5. 点击 **Commit changes…**，填写例如“发布第一篇学习笔记”，选择 **Commit directly to the main branch**，确认提交。
6. 在 [Actions](https://github.com/stone-xzh/Learn-Ai/actions) 查看最新的 **Publish Learn Ai**。出现绿色对勾后，刷新博客即可看到新文章。

只有 `posts/` 里的 Markdown 文件会被当作文章；文档和模板不会出现在博客列表中。提交文章到 `main` 就会公开发布，尚未完成的草稿可以先保存在本地。

## 文章信息怎么填

开头两行 `---` 之间是文章配置。保留字段名称，只修改内容。

| 字段 | 作用 | 示例 |
| --- | --- | --- |
| `title` | 文章标题 | `"我的第一篇 AI 学习笔记"` |
| `date` | 列表显示与排序使用的日期 | `"2026-10-22"` |
| `slug` | 文章网址名称，每篇必须不同 | `"my-first-note"` |
| `category` | 分类，归档页自动汇总 | `"学习笔记"` |
| `tags` | 标签列表 | `["AI", "入门"]` |
| `summary` | 摘要，用于搜索和订阅 | `"记录今天学到的一个概念。"` |
| `sample` | 是否显示“示例笔记”标记 | 正式文章填 `false` |

`slug` 只使用小写英文字母、数字和连接号。也请避开 `index`、`about`、`archive`、`404` 这些页面名称。已发布文章保持原来的 `slug`，之前分享的网址就不会改变。

日期需要保留引号。文件名里的日期方便整理，网站实际读取的是开头的 `date`；它不是定时发布设置。

## 常用排版

````markdown
## 小标题

这是第一段文字。

这是第二段文字，段落之间留一个空行。

**加粗重点**，以及 `行内代码`。

- 第一项
- 第二项

1. 第一步
2. 第二步

> 引用的一段文字。

[资料名称](https://example.com)

```python
print("Hello, AI")
```
````

文章标题已经由 `title` 生成，正文从 `##` 开始即可。小标题会自动进入文章目录。

## 修改已有文章

进入 `posts/`，打开对应文件，点击铅笔按钮修改，然后提交。三篇起步示例也可以直接改写：修改标题、日期、分类和正文，将 `sample` 改为 `false` 即可。

## 没有看到更新

- **任务还在运行**：等最新的 Actions 任务结束后再刷新。
- **出现红色叉号**：打开任务的 `build` 日志，检查引号、日期、必填字段和重复的 `slug`。
- **任务成功但页面没变**：用 `Ctrl + Shift + R` 强制刷新，或稍后再打开。

构建失败不会覆盖上一次成功发布的网站。把错误日志发给我，也可以继续排查。
